A tiny program that writes one single-line excuse a developer gives when
code breaks in production: it was not a DNS problem, it was the developer
"fixing" DNS at 2 a.m. — the root cause, in every sense of the term.

## Run it

```sh
python3 main.py
```

Run it as `python3 main.py` (Python 3.13, standard library alone); it writes
its text to `/output/entry.txt`.
